# 雨课堂课件自动阅读

一个用于长江雨课堂（changjiang.yuketang.cn）的 Tampermonkey 油猴脚本：自动进入未完成课件，按左侧“未读”标记翻页，读完自动校验并返回课程目录继续下一个。

## 功能

- 自动扫描未完成课件并依次进入
- 进入课件后等待首页“未读”标记消失再翻页，避免页面未加载完就跳页
- 未读页按设定间隔停留，已读页快速跳过
- 读完后自动校验仍为“未读”的页面并补读
- 最后一页额外停留 2 秒，降低阅读记录未保存的概率
- 面板与最小化胶囊带非线性过渡动画和进度条
- 支持随时暂停、返回课程目录
- 打开页面默认暂停，需要手动点“开始”

## 安装

### 方式一：一键安装（Windows，需要 Python 3）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 双击 `一键安装.bat`
3. 浏览器打开安装页后，在 Tampermonkey 中确认安装

安装器会在本机临时启动一个只监听 `127.0.0.1` 的服务，安装完成后按任意键即可停止并清理。

### 方式二：手动导入

Tampermonkey 管理面板 → 实用工具 → 从文件导入 → 选择 `自动翻页.user.js`。

## 使用

1. 打开雨课堂课程目录页（`studentLog` 页面）
2. 点击右下角面板的“开始”
3. 脚本会自动进入未完成课件并翻页，可在面板调整每页停留时间（默认 1.1 秒）
4. 面板可最小化；在课件页可点“返回目录”

## 说明

- 脚本只匹配 `https://changjiang.yuketang.cn/*`
- 课堂 ID 等参数在运行时从地址栏或本地存储推导，不包含任何个人 ID
- 仅供个人学习使用，请遵守学校和平台的相关规定
